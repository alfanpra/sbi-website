# PT Samudra Biru Indonesia

Company profile website for PT Samudra Biru Indonesia — a Jakarta-based trade company covering seafood, spices, bird’s nest, and export.

**Tagline:** _Perdagangan Terpercaya. Kemitraan Berkelanjutan._

Five pages, all in Bahasa Indonesia:

| Page         | Path        |
| ------------ | ----------- |
| Beranda      | `/`         |
| Tentang Kami | `/about`    |
| Layanan      | `/services` |
| Tim          | `/team`     |
| Hubungi Kami | `/contact`  |

## Stack

- React 18 + TypeScript + Vite
- React Router v6 (SPA)
- Vanilla CSS with custom properties
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command             | Description                             |
| ------------------- | --------------------------------------- |
| `npm run dev`       | Start the local dev server              |
| `npm run build`     | Production build to `dist/`             |
| `npm run preview`   | Preview the production build            |
| `npm run typecheck` | TypeScript check without emitting files |
